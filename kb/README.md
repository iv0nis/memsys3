# kb — extensiones opcionales de memsys3

Herramientas que amplían memsys3 sin formar parte del scaffold. memsys3 funciona igual sin ellas: no las copia `deploy.md` ni las toca `/actualizar-memsys3`. Cada una se descarga con `curl` desde su carpeta y trae su README.

| Extensión | Qué es | Cuándo usarla |
|---|---|---|
| [meet-live](meet-live/) | Servidor local + web para reuniones en vivo de `meet.md`, con túnel para humanos remotos | Coordinar agentes de distintas herramientas en tu máquina (Claude Code, Codex CLI…) o reuniones con humanos que escriben desde el navegador |

Una línea por extensión. Las entradas las añade el mantenedor del proyecto.
